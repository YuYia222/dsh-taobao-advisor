DeepSeek Harness · 桌面版插件 · Beta

淘宝选型助手

报一个型号，自动给出链接、价格、性价比与性能排序；支持品牌 + 规格筛选。登录一次淘宝即可，没有服务器、没有遥测，数据不离开你的电脑。

下载 ZIP 查看源码 安装步骤

功能

功能状态
单品比价：最便宜 / 性价比最高 / 性能最强 + 全部候选链接可用
品牌筛选（自动识别 30+ 品牌）可用
规格筛选（极数 3P、电流 C32、功率 7.5KW、容量 256G），可与品牌叠加可用
三种登录：面板内扫码 / 短信验证码 / 账号密码可用
后台运行（无头浏览器），需要过滑块时可切到可见窗口可用
代问客服：生成问价话术并发送实验能力
批量比价 + 导出 Excel测试中，未充分验证

批量比价仍处测试阶段：按行串行搜索、依赖页面结构解析，尚未覆盖多种品类与较大行数。请先用 2–3 行试跑，确认导出的表格无误后再正式使用。

安装

一条命令（需要本机有 git）：

dsh plugin --profile desktop install git+https://github.com/YuYia222/dsh-taobao-advisor.git

也可以不用命令行：点顶部「下载 ZIP」→ 解压 → DSH 左侧「插件」→ 安装插件 → 选解压出的目录。

装好后重启 Harness，左侧栏出现「淘宝选型助手」，点开扫码登录即可。

你的数据会不会被传走？

不会。这个插件没有作者服务器、没有遥测，也不会把你的任何数据回传给作者。

  • 没有后端：逻辑全在你本机（DSH 宿主进程 + 你的浏览器），作者没有接收端。
  • 没有账号体系：不收集邮箱、机器码、使用统计，没有激活 / 上报 / 心跳。
  • 出网只有两类：访问 taobao.com / tmall.com 的正常页面请求；商品图片经本机代理转发（只允许 *.alicdn.com、*.taobao.com、*.tmall.com），图片仍来自淘宝。
  • 面板接口只监听本机：路由绑定 127.0.0.1，并校验来源必须是回环地址，非本机请求直接 403。
  • 数据只落在本机：登录态在浏览器配置目录，导出的 Excel 在本地目录，密码只填入浏览器表单、不写盘。
  • 可自行审计：代码全在本仓库，搜 fetch( 即可看到所有出网位置。

如果你在 DSH 里主动开启了远程访问 / 局域网共享，那是 DSH 自身的能力，与插件无关。

如何更新

重新执行安装命令即可拉取最新版本，然后重启 DSH：

dsh plugin --profile desktop install git+https://github.com/YuYia222/dsh-taobao-advisor.git

想固定版本就用标签安装（如 #v0.1.0-beta.1），不会被后续更新影响。更新不影响淘宝登录态。

已知限制

  • 仅在 Windows + Edge/Chrome 上验证过。
  • 列表价是最低 SKU 起价，多规格商品请以商品页所选规格的实价为准。
  • 型号匹配为启发式规则，「全部链接」表保留原始候选供人工复核。
  • 批量比价单次最多 30 行，逐条串行；功能仍在测试。
