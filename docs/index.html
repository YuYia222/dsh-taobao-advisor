DeepSeek Harness · 桌面版插件

淘宝选型助手

报一个型号，自动给出链接、价格、性价比与性能排序；支持品牌 + 规格筛选、多项批量比价并导出 Excel。登录一次淘宝即可，账号数据只留在你自己的电脑上。

下载 ZIP 查看源码 安装步骤

能做什么

单品比价

输入型号，给出「最便宜 / 性价比最高 / 性能最强」三组推荐与全部候选链接。

品牌 + 规格筛选

自动识别品牌（正泰、施耐德、Apple…）与规格（极数 3P、电流 C32、功率 7.5KW、容量 256G），可叠加。

批量比价 + Excel

上传模板表格，一行一件商品，导出含「汇总 / 全部链接」两张表的结果。

后台运行

默认无头浏览器，屏幕不弹窗；需要过滑块时一键切到可见窗口。

三种登录

扫码（二维码直接显示在面板里）、短信验证码、账号密码。

代问客服

自动生成问价话术，确认后打开客服窗口发送（实验能力）。

界面

安装后出现在左侧栏；面板内含登录、比价、批量比价三个区域。

安装

一条命令（需要本机有 git）：

dsh plugin --profile desktop install git+https://github.com/YuYia222/dsh-taobao-advisor.git

也可以不用命令行：点顶部「下载 ZIP」→ 解压 → DSH 左侧「插件」→ 安装插件 → 选解压出的目录。

装好后重启 Harness，左侧栏出现「淘宝选型助手」，点开扫码登录即可。

已知限制

  • 仅在 Windows + Edge/Chrome 上验证过。
  • 列表价是最低 SKU 起价，多规格商品请以商品页所选规格的实价为准。
  • 淘宝改版可能让抓取规则失效，需要更新 lib/taobao.js。
  • 型号匹配是启发式的，「全部链接」表保留原始候选供人工复核。
